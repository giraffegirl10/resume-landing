- A responsive React frontend connected to a Python and FastAPI REST API.
- PostgreSQL storage for user profiles and unlockable cosmetics, with JWT session authentication.
- A Docker setup for consistent development and production environments.
- Automated PyTest backend tests on code commits through GitHub Actions.
