### Inside the application

- FastAPI endpoints for creating, reading, updating, and deleting posts, with author permissions for changes.
- Jinja2 pages for the post feed, individual posts, and author archives, alongside JSON API responses.
- User account, login, and password-reset pages.
- Asynchronous SQLAlchemy queries, Alembic database migrations, and PyTest tests for posts and users.
